# Repository sample for measure-repo-funnel.ts. Frozen 2026-09-07.
#
# The sample is pre-registered: the query below was written first, run once, and
# the result taken in the order it came back. No repository was added, dropped or
# swapped after seeing what it measured.
#
# Strata: 10 languages x 3 repository-size bands, 2 repositories per cell, 60 total.
#
#   languages  TypeScript, JavaScript, Python, Go, Rust, Java, C#, PHP, Ruby, C++
#              GitHub's own primary-language label, one per repository.
#   size       small 0.1-2 MB, medium 2-20 MB, large 20-200 MB
#              GitHub's `size` field, in KB. It measures the repository on
#              GitHub, history included, so it is a proxy for the working tree
#              and not the working tree itself.
#
# Query, per cell, against the GitHub search API on 2026-09-07:
#
#   language:<L> size:<band> stars:100..5000 pushed:>2026-03-07
#   archived:false is:public mirror:false template:false
#   sort=stars order=desc
#
# Inclusion rule: take the first 2 results of each cell. If a clone fails, take
# the next result in that cell's order. The next four are recorded below each
# cell as reserves so a replacement stays inside the pre-registered order rather
# than becoming a fresh choice.
#
# Why these filters:
#
#   stars 100 to 5000   A floor of 100 keeps abandoned experiments out; a ceiling
#                       of 5000 keeps the sample from becoming a list of
#                       exceptional mega-projects and curated link collections,
#                       which are not what anyone drops into a context window.
#   pushed within 6 mo  A repository nobody has touched since 2026-03-07 does not
#                       describe how code is laid out now.
#   archived, mirror,   All three are copies or corpses rather than working
#   template            projects.
#   forks               Excluded by the search API's default.
#
# Known bias, to be carried into the article's limitations, not hidden here:
#
#   1. Sorting by stars descending inside a 5000-star ceiling means every
#      repository here sits near the ceiling. The sample spreads over language
#      and size, not over popularity. A well-known project carries more CI
#      config, more tests and more lockfiles than a private work repository, so
#      the measured non-source share is likely to be an over-statement of what a
#      solo developer's folder looks like.
#   2. The language label is GitHub's primary language. A polyglot repository is
#      counted once, under whichever language has the most bytes.
#   3. Two entries are documentation collections rather than codebases
#      (gopl-zh.github.com, iOS-Weekly). They were kept because removing them
#      after seeing them would make the sample a choice rather than a query.
#      They are expected to sit at the top of the docs-share distribution and
#      should be named there.
#
# Run:
#   pnpm --filter @fileconcat/cli measure-funnel --repos scripts/repo-sample-2026-09-07.txt
