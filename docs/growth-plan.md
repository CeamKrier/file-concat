# Growth plan — positioning + execution tracker

Source: the 2026-07-30 positioning/growth grill ("FileConcat Konumlandırma ve
Büyüme Stratejisi"). This is the **execution tracker**; the strategy rationale
lives in the source brief. Builds on [DISCOVERABILITY.md](./DISCOVERABILITY.md)
(SEO audit) and **ADR-0006** (positioning). Long-running effort — check items off
here as they ship.

## Positioning (decided 2026-07-30)

- **Refinement of ADR-0006, not a reversal.** The homepage leads with the
  outcome/pain ("solve the AI file upload limit"), which is a **superset that
  still contains the developer** (a repo is just files). No new ADR: ADR-0006's
  "broaden the invitation, keep the anchor" already covers this, and it flagged
  the copy work as _deliberately not an architectural choice_.
- **The one defensible difference is fully local PDF/Office extraction** (ADR-0003).
  Every user-facing surface leads with it.
- **Vocabulary is surface-scoped, not global** (pending final call, see Open
  questions): keep "combine files" (a preferred word _and_ our current ranking
  anchor); drop "concat" / "AI-ready" / "LLM-ready" from marketing copy; "token"
  allowed as a feature label, not in headlines. Internal canonical term stays
  **"bundle"** — `CONTEXT.md` and the ADRs are unchanged.

## Repo-grounded corrections to the brief

1. **T4 already exists.** `llms.txt` + `llms-full.txt` ship from `public/`
   (DISCOVERABILITY.md "Strong today"). Work is a rewrite, not a create.
2. **T1 vs DISCOVERABILITY tension (the sharp one).** Our _entire_ current search
   footprint is the homepage ranking **#1 for "file concat tool"** (114 impr,
   pos 1.2, **0% CTR**) plus the concat/combine family. DISCOVERABILITY's thesis
   was "rescue that CTR." The brief repoints the copy at file-limit queries we do
   **not** rank for yet. Risk: dropping "concat" from the title may forfeit the
   only ranking we have. Likely mitigation: keep "combine files", add
   "limit/unlimited + platform names", drop only "concat/AI-ready". Decision open.
3. **Branded/unbranded is partly answered.** DISCOVERABILITY already found **73%
   of clicks are brand**; the brief lists this as fully open. Partly done.
4. **Two measurement snapshots.** GSC 91d = 2,985 impr; brief 28d = 1,770 impr.
   Daily rate ~doubled (33 -> 63/day) — the blog work is moving impressions. Keep
   both windows, don't conflate them.

## New ideas (2026-07-30, not in the original brief) — to evaluate

- **Content reduction before bundling.**
  - _Deterministic strippers_ — comment lines, `<style>`/`<script>` blocks,
    minified blobs. Cheap, on-brand, no model, testable pure functions.
    **Ship-candidate.** Relates to brief Gen-A #3 (token-budget targeting).
  - _Local-LLM semantic reduction_ — drop/summarize low-value files with a local
    model. Heavy (WebGPU / transformers.js), non-deterministic, in tension with
    the "predictable + light + nothing-leaves-browser" brand. **Evaluate, don't
    assume.** Note: comment/style stripping does **not** need an LLM.
- **MCP / agent-native packaging** of the core (concat + PII scan) — brief
  Gen-B #4. MCP users are developers/agent-builders, a **different segment** than
  T1/T2's non-dev audience; it re-invites the developer (consistent with the
  superset framing). Candidate distribution shape for the open-source core.

## Measurement (per sprint)

- **Primary:** GSC impressions + indexed page count.
- **Secondary:** AI citations + cited-page count (now **2**) + unbranded share.
- **Health:** dead-click rate down (from 24.39%), returning-user 30.6% held.
- **Ignore:** CTR — it falls as the long tail opens; that is the expected result.
