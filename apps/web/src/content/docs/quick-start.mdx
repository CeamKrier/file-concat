# Quick start

You can be looking at a tokenised, filtered project bundle in under a
minute. The two paths below cover almost every use.

## Path 1: local files

1. Open [fileconcat.com](https://fileconcat.com).
2. Drop a folder, files, or an archive (zip, 7z, rar, tar and
   [the others it unpacks](/docs/formats)) onto the drop zone on the landing
   page, or use **Browse files** / **Browse folder**. Archives are unpacked
   automatically and their contents flow through the same filtering.
3. FileConcat narrates the work (reading your files, skipping noise,
   counting tokens) and then lands on the result screen, "Your bundle is
   ready." The screen shows the files combined, the token count, and how
   much noise was skipped.
4. Click **Copy** or **Download** to take the output with you. Either
   way you get the whole bundle as one file.

## Path 2: remote source

1. On the landing page, find the link field under the drop target.
2. Paste a repository, Gist or page link into it. The field reads the URL
   and tells you what it found. The host select next to it only decides
   where a bare `owner/repo` goes.
3. Press **Fetch**. FileConcat fetches the files and runs the same
   processing as a local drop, then shows the result screen.
4. Adjust and emit as in Path 1.

## Filter and emit

Both paths land on the same result screen:

- The result screen's **Format** control switches the output between
  **XML**, **Markdown**, and **Plain**.
- The **Adjust what's included** button in the top bar opens the
  **Files** pane. It holds a filter box, By type chips, the file tree
  with each file's share, and the **Ignore** and **Only include** glob
  textareas. Every change updates the bundle live.
